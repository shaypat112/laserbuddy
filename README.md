# laserbuddy

A cinematic, scroll-driven product site for LaserBuddy: the open-source desk companion that sees parts, understands a project, and points to what you need next.

## Run the site

```bash
npm install
npm run dev
```

The site is frontend-only. It renders the real LaserBuddy STL assets in WebGL and uses the project documentation for all product claims and specifications.

## Production build

```bash
npm run build
```
